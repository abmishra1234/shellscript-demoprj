# Shell Script Demo Project

A collection of shell script examples and utilities to help you learn and practice shell scripting.

## Project Structure

```
shellscript-demoprj/
├── examples/          # Example shell scripts demonstrating various concepts
├── utils/            # Utility scripts for common tasks
├── HELP.md           # Additional resources and tips
└── README.md         # This file
```

## Getting Started

### Prerequisites

- Bash shell (version 4.0 or higher recommended)
- Unix-like operating system (Linux, macOS, WSL on Windows)

### Running the Scripts

1. Clone this repository
2. Navigate to the script directory
3. Make scripts executable: `chmod +x script-name.sh`
4. Run the script: `./script-name.sh`

## Examples Included

### Basic Scripts
- **hello_world.sh** - Simple hello world example
- **variables.sh** - Working with variables and user input
- **conditionals.sh** - If-else statements and comparisons

### Utility Scripts
- **backup.sh** - Simple backup utility
- **system_info.sh** - Display system information
